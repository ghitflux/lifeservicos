# Assets

Este diretório contém os assets do aplicativo.

## Imagens necessárias

Você precisa adicionar os seguintes arquivos:

- `icon.png` - Ícone do app (1024x1024px)
- `splash.png` - Splash screen (1242x2436px)
- `adaptive-icon.png` - Ícone adaptativo Android (1024x1024px)
- `favicon.png` - Favicon para web (48x48px)

## Como gerar ícones

Você pode usar ferramentas online como:
- https://www.appicon.co/
- https://easyappicon.com/

Ou criar manualmente no Figma/Photoshop.

## Diretrizes de design

- Use cores da marca: Primary #007AFF
- Mantenha design simples e reconhecível
- Teste em diferentes tamanhos
